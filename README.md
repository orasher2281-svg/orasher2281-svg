## 🚀 Featured Projects

### 🥗 [RightBite](https://github.com/orasher2281-svg/RightBite)
Full-stack nutrition & meal-tracking application. Users register with their body metrics, and the system automatically calculates personalized daily calorie and macronutrient targets. Meals are logged by searching a food database, or by adding new foods via **AI (Google Gemini)** — from a name, a free-text description, or an uploaded photo. A daily dashboard visualizes progress toward calorie and macro targets.

![.NET](https://img.shields.io/badge/.NET-512BD4?style=flat-square&logo=dotnet&logoColor=white) ![C#](https://img.shields.io/badge/C%23-239120?style=flat-square&logo=csharp&logoColor=white) ![Angular](https://img.shields.io/badge/Angular-DD0031?style=flat-square&logo=angular&logoColor=white) ![EF Core](https://img.shields.io/badge/EF%20Core-512BD4?style=flat-square&logo=dotnet&logoColor=white) ![SQL Server](https://img.shields.io/badge/SQL%20Server-CC2927?style=flat-square&logo=microsoftsqlserver&logoColor=white) ![JWT](https://img.shields.io/badge/JWT-000000?style=flat-square&logo=jsonwebtokens&logoColor=white) ![Gemini AI](https://img.shields.io/badge/Google%20Gemini-8E75B2?style=flat-square&logo=googlegemini&logoColor=white)

**Highlights:**
- Secure user authentication (JWT + password hashing with BCrypt)
- Automatic calculation of personalized calorie & macro targets (Mifflin-St Jeor formula)
- AI-powered food entry (Google Gemini) — from a name, a free-text description, or a photo
- Daily dashboard visualizing progress toward nutrition targets
- Backend built following **Clean Architecture** principles — full separation between Domain, Infrastructure, Service, and API layers

### 🎓 [Student Grants Management System](https://github.com/orasher2281-svg/student-grants-management-system)
A complete backend system (Node.js, Express, MongoDB) managing the full lifecycle of student grant applications — authentication, a multi-step application form, document uploads, and admin-side review and approval. A React client completes the project as an end-to-end demonstration.

![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white) ![Express](https://img.shields.io/badge/Express-000000?style=flat-square&logo=express&logoColor=white) ![MongoDB](https://img.shields.io/badge/MongoDB-47A248?style=flat-square&logo=mongodb&logoColor=white) ![JWT](https://img.shields.io/badge/JWT-000000?style=flat-square&logo=jsonwebtokens&logoColor=white) ![React](https://img.shields.io/badge/React-61DAFB?style=flat-square&logo=react&logoColor=black)

**Highlights (backend-focused project):**
- Multi-step application form (personal, family, education, and bank details) with status-aware conditional validation
- Draft saving with automatic restore on return
- Supporting document uploads (Multer) and status tracking (Draft → Pending → Approved/Rejected)
- Admin dashboard with application filtering and approval workflow
- Role-based authorization (student vs. admin) enforced through dedicated middleware
